# ATM Interface

## Project Name

ATM Interface

## Objective

The objective of this project is to create a Java-based console application that simulates the basic functionality of an Automated Teller Machine (ATM). Users can log in using a User ID and PIN and perform banking operations such as checking transaction history, withdrawing money, depositing money, transferring money, and checking their account balance.

## Features

* User ID and PIN authentication
* Maximum 3 incorrect login attempts
* Transaction History
* Withdraw money
* Deposit money
* Transfer money to another account
* Check account balance
* Insufficient balance validation
* Invalid amount validation
* Transaction history stored using ArrayList
* Multiple Java classes using Object-Oriented Programming

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* HashMap
* Scanner
* Conditional Statements
* Switch Case

## How to Run

1. Download or clone this repository.
2. Open the project in Eclipse, IntelliJ IDEA, or any Java IDE.
3. Make sure all Java files are in the same project:

   * Main.java
   * ATM.java
   * Account.java
   * Bank.java
   * Transaction.java
4. Run the `Main.java` file.
5. Enter a valid User ID and PIN.
6. Select options from the ATM menu to perform transactions.
7. Select Quit to exit the program.
