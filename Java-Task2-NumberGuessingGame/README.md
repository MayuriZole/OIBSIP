# Number Guessing Game

## Project Name

Number Guessing Game

## Objective

The objective of this project is to create a Java-based game where the computer generates a random number and the user tries to guess it. The program provides hints such as "Too High" and "Too Low" until the correct number is guessed or the maximum number of attempts is reached.

## Features

* Generates a random number between 1 and 100
* Accepts user input using Scanner
* Displays "Too High" when the guess is greater than the correct number
* Displays "Too Low" when the guess is lower than the correct number
* Displays "Correct" when the user guesses the correct number
* Tracks the number of attempts
* Maximum attempt limit of 7 attempts
* Displays a message when the user wins or loses
* Play Again option for multiple rounds
* Input validation for invalid values

## Technologies Used

* Java
* Java Random class
* Scanner
* Loops
* Conditional Statements

## How to Run

1. Download or clone this repository.
2. Open the project in Eclipse, IntelliJ IDEA, or any Java IDE.
3. Open the `NumberGuessingGame.java` file.
4. Compile and run the program.
5. Enter a number between 1 and 100.
6. Follow the hints and try to guess the correct number.
